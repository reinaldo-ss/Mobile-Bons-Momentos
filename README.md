## 🚀 Versões Disponíveis

Este repositório disponibiliza duas implementações mobile do ecossistema **Bons Momentos**, organizadas por linguagem e propósito:

### 1. Projeto em Kotlin (`Projeto em Kotlin/`)
Aplicativo voltado para a operação logística e de entregas (**BonsMomentosEntregador**), conectado diretamente ao banco de dados em nuvem.
* **Stack & Tecnologias:** Kotlin, Android SDK, XML Layouts, Supabase (PostgreSQL & Auth).
* **Funcionalidades:**
  * Autenticação de entregadores utilizando **CPF**.
  * Listagem e acompanhamento de pedidos prontos para entrega em tempo real.
  * Atualização de status de entrega sincronizada com o painel administrativo e a cozinha.
* **Arquivos incluídos:**
  * `app-bons-momento.apk` — Instalador pronto para uso direto em dispositivos Android.
  * `Projeto-Bons-Momentos-Mobile.rar` — Código-fonte completo para abertura e compilação no Android Studio.

### 2. Projeto em Java (`Projeto em Java/`)
Implementação nativa desenvolvida em Java para dispositivos Android.
* **Stack & Tecnologias:** Java, Android SDK, Gradle.
* **Arquivos incluídos:**
  * `bons-momentos.apk` — Instalador compilado pronto para instalação e testes.
  * `Bons-Momentos-Java.zip` — Código-fonte completo para importação no Android Studio.

| Versão | Diretório | Código-Fonte | Instalador (APK) | Tecnologias Principais |
| :--- | :--- | :--- | :--- | :--- |
| **Kotlin** | `Projeto em Kotlin/` | `Projeto-Bons-Momentos-Mobile.rar` | `app-bons-momento.apk` | Kotlin, Android SDK, Supabase |
| **Java** | `Projeto em Java/` | `Bons-Momentos-Java.zip` | `bons-momentos.apk` | Java, Android SDK, Gradle |
